# Code Style & Conventions

## Naming Conventions
- Komponente: PascalCase (UniversalCard.jsx)
- Fajlovi: camelCase ili kebab-case 
- Varijable: camelCase
- Constants: UPPER_CASE

## File Structure
- Components u `/web/src/components/`
- Services u `/web/src/services/`
- Utils u `/web/src/utils/`
- Server models u `/server/models/`
- Server routes u `/server/routes/`

## Technology Patterns
- Material-UI komponente za UI
- Axios za API pozive
- Mongoose za MongoDB modele
- JWT za autentifikaciju
- Form handling sa useState

## Language
- Komentari i UI tekst na bosanskom/srpskom/hrvatskom
- Varijable i funkcije na engleskom
