# Plan za implementaciju sistema otkazivanja predavanja

## Pregled funkcionalnosti
Sistem koji omogućava:
1. Korisnicima da prijave otkazivanje predavanja
2. Dashboard gdje se prikazuju sve prijave za otkazivanje
3. Admin opcije za odobravanje/odbijanje prijava
4. Automatsko otkazivanje predavanja nakon 3 prijave

## Glavni dijelovi za implementaciju
- Frontend: Forma za prijavu otkazivanja u pojedinačnom predavanju
- Backend: API rute za rukovanje prijavama
- Dashboard: Prikaz i upravljanje prijavama
- Automatska logika za otkazivanje nakon 3 prijave
